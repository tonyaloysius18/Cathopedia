# Prayer background image prompts

Reference list for generating background art for each prayer's detail screen,
matching the existing house style (see `portrait_joseph.jpg` / `apparition_lourdes.jpg`
in `shared/src/commonMain/composeResources/drawable/`): classical academic
sacred oil painting, warm golden light, rich earthy palette, soft halo glow
where devotionally appropriate, fine brushwork, reverent and still — no text,
no watermark, no signature.

**Format to match the existing asset convention**: portrait orientation,
3:4 aspect ratio (900×1200px), so it can slot in next to the other
`<type>_full_<slug>` background images already in the app.

Each entry below is a full prompt — the shared style clause plus a
scene/subject clause specific to that prayer. Slug is the `content/prayers/<slug>.json`
id, so whatever you name the file when you hand it back to me can just be
`prayer_full_<slug>.jpg` to match the existing naming pattern.

Since the prayer screen shows this at low opacity behind readable text,
favor compositions with open, uncluttered space (sky, wall, background) in
the upper-middle third rather than a face or focal object dead-center — the
prayer title and body will sit on top of that area.

## Once you have the images

Save each as `prayer_full_<slug>.jpg`, matching the naming convention already
used for `apparition_full_<slug>.jpg` / `portrait_full_<slug>.jpg`
(900×1200px). Hand them back in a batch and I'll:

1. Drop them into `shared/src/commonMain/composeResources/drawable/`.
2. Add the explicit `import com.ynotlabs.cathopedia.resources.prayer_full_<slug>` lines to `Portraits.kt` (per the existing gotcha — Compose Resources codegen needs the named import or it's "unresolved reference" despite the file being present).
3. Wire a background `Image` composable into `PrayerDetailScreen.kt`'s reading content, low alpha, behind the text — matching whatever opacity treatment the saint/apparition detail screens already use, if any exists to copy from.
