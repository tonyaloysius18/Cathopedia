# Religious Orders — image generation brief

51 images, one per order. Each is a single figure in that order's **distinctive religious habit**, so it reads at a glance. Same house style as the app's other art: classical academic sacred oil painting, warm golden light, rich earthy palette, half-length, reverent. **Transparent background — no scenery, ground or frame.** No official/modern logos or trademarks — a plain heraldic emblem is fine where noted. No text or watermark. Square 1:1, 1024x1024. Save each as `order_<slug>.png` (512px transparent PNG) in `shared/src/commonMain/composeResources/drawable/` (resolves by basename; content path `hub/orders/order_<slug>.png`).

**Negative prompt (all):** `text, letters, labels, watermark, signature, frame, border, background scenery, buildings, modern clothing, cartoon, low detail, extra limbs, distorted hands`
