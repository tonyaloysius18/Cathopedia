# Sacred Symbols — Background/Icon Image Generation Brief

Generate **88 emblem images**, one per symbol in the Cathopedia *Sacred Symbols* hub. They form a single cohesive icon set shown in the symbol reference pages, so consistency across all 88 matters more than any single image.

Each numbered item is a **complete, self-contained prompt** — the shared style is repeated in every one so you can paste them individually. Use each exactly as written and save with the given filename.

## Rules for every image

- **Style (identical for all 91):** Sacred gilded emblem icon in an illuminated-manuscript style: a single luminous gold symbol, centered and symmetrical, rendered with fine gold linework and a gentle embossed / relief sheen, kept legible with a subtle darker outline; reverent and timeless. IMPORTANT: fully TRANSPARENT background (PNG alpha) — the symbol alone, no field, no backdrop, no glow behind it, nothing but the emblem on transparency. No caption text, no labels, no watermark, no signature, no border frame. Square 1:1 aspect ratio, 1024×1024, exported as a transparent PNG.
- **Transparent background is required.** Export a PNG with a real alpha channel — no white box, no coloured field, no glow disc behind the symbol. Only the gold emblem should be opaque.
- **Composition:** one symbol only, centered, generous margin; no scene, no background objects.
- **Consistency:** same gold tone and same line weight across the whole set.
- **Lettering:** only the letter-based symbols (Chi-Rho, IHS, Alpha & Omega, INRI, the Marian monogram) may contain letters — and those letters ARE the symbol. No other text anywhere.
- **One image per prompt.** Do not combine symbols or make a grid/sheet.
- **Save** each file with the exact `Save as` filename (`.png`). Target folder in the repo: `content/hub/symbols/`.
