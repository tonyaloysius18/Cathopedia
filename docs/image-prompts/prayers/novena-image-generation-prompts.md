# Novena Background Images — Generation Brief

Generate **12 background images**, one for each novena listed below. These sit
behind readable prayer text on the prayer detail screen in the Cathopedia app,
so they must share one consistent visual style and leave open, calm space near
the top for text to rest over.

Each numbered item is a **complete, self-contained prompt** — it already
includes the shared style, the scene, and the format. Use it exactly as written.

## Rules for every image

- **Style:** classical academic sacred oil painting, reverent and devotional;
  warm golden light, rich earthy palette, fine brushwork, soft halo glow where
  appropriate; still and prayerful.
- **Format:** portrait orientation, 3:4 aspect ratio, 900×1200 px.
- **Composition:** keep the **upper-middle third open and uncluttered** (soft
  sky, glow, or wall) — no face or focal object dead-center-top — because the
  prayer title and body will be laid over that area at low opacity.
- **Absolutely no** text, lettering, captions, watermarks, or signatures
  anywhere in the image. If any appears, regenerate until clean.
- Generate **one image per prompt** (do not combine multiple novenas into a
  single image or a grid/collage).
- **Save each file** using the exact filename given under its prompt.
