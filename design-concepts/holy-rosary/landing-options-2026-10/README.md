# Cathopedia Rosary landing options

Three UI concept previews created with the built-in image generator. These are alternative structures for the same landing page. Each retains the blue-and-white rosary, silver chain, crystal-blue crucifix and mystery artwork. UI copy stays in French to match the supplied screen.

The current layout reserves a full-width square area for a tall narrow image. That area, followed by the text and Start button, delays access to the mystery gallery. These alternatives reduce the rosary's vertical space and strengthen the path to prayer.

## Option 1 — Compact header

![Compact header with a four-mystery grid](/Users/tonyaloysius/Documents/Cathopedia/design-concepts/holy-rosary/landing-options-2026-10/option-1-compact-header.png)

Option 1 was selected and implemented. Start opens today's set directly. Tapping a mystery opens its five mysteries in a bottom panel with a Start action for that set. Saved progress has a separate Resume row.

## Option 2 — Mystery selector (recommended)

![Horizontal rosary, mystery selector and bottom Start action](/Users/tonyaloysius/Documents/Cathopedia/design-concepts/holy-rosary/landing-options-2026-10/option-2-mystery-selector.png)

Tap a set to select it. The bottom button changes to the selected set and starts that set directly. The selected state is visible through both an outline and a check. The action area reserves space so it never covers the final row. Mystery details can open through the selected artwork without changing the prayer selection. Saved progress remains a distinct Resume action.

## Option 3 — Today focus

![Today's mysteries with a small rosary and alternate-set shelf](/Users/tonyaloysius/Documents/Cathopedia/design-concepts/holy-rosary/landing-options-2026-10/option-3-today-focus.png)

The primary button starts today's recommended set. Tap an alternate set in the shelf to select it and update the featured prayer. The shelf permits horizontal browsing; each category retains its name and prayer days. Saved progress remains a distinct Resume action.

## Shared UX details

- One primary Start action, with the current selection named clearly.
- Complete rosary image visible in a compact area, without a large empty image frame.
- Text remains on plain surfaces; day labels and mystery names stay readable.
- Touch targets, top navigation and bottom safe areas are respected.
- The user's chosen layout can support both the light and dark Marian palettes; the structural choice and the color mode are independent.
- Resume is shown only when saved progress exists. Completion history can follow the mystery content below the first viewport.
- On small screens or large text settings, content scrolls naturally rather than shrinking the text. In Option 2 the Start area remains docked while the selection list scrolls.

Option 1 is now implemented in Cathopedia. Options 2 and 3 remain alternative concepts. The existing transparent rosary artwork is retained. [Actual app previews and UX notes](/Users/tonyaloysius/Documents/Cathopedia/design-concepts/holy-rosary/implemented-option1/README.md).
