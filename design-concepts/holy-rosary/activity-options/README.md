# Rosary activity UI options

Three preview concepts for the activity table in the Holy Rosary landing page. The three original images are design proposals. The weekly journal (option 3) has now been selected and implemented in the app.

1. **Calendar** — a monthly date grid with weekday labels, completed-day markers, a today outline, month navigation and a clear legend. Recommended for familiar date browsing.
2. **Bead grid** — five compact weeks represented by connected circular beads, date-range labels, completion counts and distribution bars by mystery set.
3. **Weekly journal** — a compact seven-day strip plus a dated completion summary and a two-column mystery breakdown.

All use Cathopedia's navy, Marian blue, gold and cream. Sample totals match the reference screenshot: 2 completed, 2 this month, Sorrowful 2 and all other sets 0. Dates in the concepts are illustrative: both completions are shown on 9 October 2026, with 11 October as today.

Generated using the built-in `image_gen` tool. Final images are `01-calendar.png`, `02-bead-grid.png`, and `03-weekly-journal.png`. Full generation and correction prompts, reference path and saved paths are recorded in `prompts.json`.
